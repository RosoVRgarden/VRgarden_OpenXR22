# RosoVRgarden_OpenXR22
 
This template is ready to use on the Oculus Quest and the HTC Vive Pro. It includes locomotion (action based), direct interactables (right), ray interactable (left), simple objects (sonic ball, transform), physics-based objects (cabinet, door), and a lift. It also uses the idea of presence to trigger events.

Requires: Unity 2022.3.62f3 with XR Interaction Toolkit 2.5.2.

Thanks to Another Creative Technologist, C-Through, ValemVR for their tutorials.
